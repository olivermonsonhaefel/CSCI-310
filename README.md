# Trojan Rideshare (CSCI-310)

An Android application designed for ridesharing, built for CSCI-310.

## Features
- **User Authentication**: Secure sign-in and registration using Firebase Authentication.
- **Ridesharing Management**: Connect riders and drivers seamlessly.
- **Cloud Firestore**: Real-time data storage and synchronization.

## Tech Stack
- **Language**: Java
- **UI**: Android Views, Material Design 3, Edge-to-Edge support
- **Backend**: Firebase (Auth & Firestore)
- **Testing**: JUnit, AndroidX Test / Espresso

## Getting Started
1. Clone the repository.
2. Open the project in Android Studio.
3. Add your `google-services.json` file to the `app/` directory.
4. Sync project with Gradle files and run on an emulator or physical device.
